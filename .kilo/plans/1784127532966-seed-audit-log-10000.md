# Plan: Seed 10,000 Audit-Log Records

## Goal
Add a standalone, append-only seeder that inserts **10,000** `audit_logs` rows using realistic
faker data, matching the 3 sampled action shapes. Rows reference **real existing orders and
users** already in the DB (no `npm run seed` required, no data loss).

## Constraints (confirmed)
- **Append-only**: every run inserts another 10,000 rows. No delete/clear logic.
- **3 actions only**: `order_created`, `cash_payment_confirmed`, `khqr_payment_confirmed`
  (do NOT include `order_cancelled`).
- **Real FKs**: MySQL enforces FK on `audit_logs.order_id → orders.id` and
  `audit_logs.actor_user_id → users.id`. Therefore all `order_id`/`actor_user_id` must be
  existing row IDs pulled from the DB. No synthetic/non-existent IDs.
- Do **not** gate on `npm run seed`; the DB already has orders/cashiers. Warn (not fail hard)
  if either pool is empty, then exit gracefully.

## New file: `backend/src/scripts/seed-audit-logs.js`
Mirror the style of `seed-bulk-products.js` (faker, `ensureDatabaseExists`, sync in dev,
`finally` closes sequelize, `process.exitCode = 1` on error).

Imports: `dotenv/config`, `faker`, `sequelize, { ensureDatabaseExists }` from `../config/db.js`,
`{ Order, AuditLog }` from `../models/index.js`, and `roundUsd, toKhr, randomRecentDate` +
`SEED_MARKER` from `../scripts/seeders/helpers.js` + `../scripts/seeders/data.js`.

Constants:
- `AUDIT_LOG_COUNT = 10000`
- `BATCH_SIZE = 1000`
- `SEED_BASE = 20260715` (call `faker.seed(SEED_BASE)` once for reproducible values within a run)

### Data load
1. `await ensureDatabaseExists(); await sequelize.authenticate();` sync only in dev
   (`{ alter: true }` when `NODE_ENV === 'development'`).
2. Load orders (needed columns only):
   `Order.findAll({ attributes: ['id','stall_id','cashier_id','subtotal_usd','total_usd','payment_method'] })`.
3. Split into `cashOrders` (`payment_method === 'cash'`) and `khqrOrders` (`payment_method === 'khqr'`).
4. Load fallback cashiers for actor: `User.findAll({ where: { role: ['cashier','manager'] }, attributes: ['id'] })`.
5. If `orders.length === 0` → `console.warn` and `return`. If `cashiers.length === 0` → warn/return.

### Row builder (per index)
Pick action by fixed weights: `order_created` 0.40, `cash_payment_confirmed` 0.35,
`khqr_payment_confirmed` 0.25. If the chosen action needs a pool that is empty, fall back to
`order_created` so FKs always resolve.

`created_at = randomRecentDate()` (spread across last 14 days, consistent with other seeders).
`actor_user_id` = order's `cashier_id` (fallback to a random cashier id).

Details objects (keys must match the provided samples exactly, plus `seeded_by: SEED_MARKER`):

- **order_created**: source a random order `o`:
  ```
  { seeded_by, stall_id: o.stall_id, item_count: <1-4>,
    subtotal_usd: o.subtotal_usd, total_usd: o.total_usd,
    total_khr: toKhr(o.total_usd), payment_method: o.payment_method }
  ```
- **cash_payment_confirmed**: source a random `cashOrders` row `o`:
  ```
  { seeded_by, stall_id: o.stall_id, cashier_id: o.cashier_id, total_usd: o.total_usd,
    cash_received_usd: roundUsd(o.total_usd + tip), change_due_usd: roundUsd(tip),
    confirmed_by_role: 'cashier' }
  ```
  where `tip = faker.helpers.arrayElement([0, 0.25, 0.5, 1, 5])`.
- **khqr_payment_confirmed**: source a random `khqrOrders` row `o`:
  ```
  { seeded_by, hash: faker.string.hexadecimal({ length: 64, prefix: '' }),
    amount: o.total_usd, qr_md5: faker.string.hexadecimal({ length: 32, prefix: '' }),
    source: 'bakong_status_check', currency: 'USD', checked_by_role: 'cashier',
    payment_reference: `TOUB-${o.id}-${faker.string.alphanumeric(8).toUpperCase()}` }
  ```

### Insertion
Build an array of `AUDIT_LOG_COUNT` plain objects (no per-row `create` — too slow for 10k).
`bulkCreate` in `BATCH_SIZE` chunks inside a single `sequelize.transaction`. Do NOT set
`validate:false` (keep defaults). Log progress every batch.

### Logging / exit
- `console.log` count inserted and elapsed time.
- `.catch` sets `process.exitCode = 1`; `.finally` closes sequelize.

## Package script
Add to `backend/package.json` `scripts`:
`"seed:audit": "node src/scripts/seed-audit-logs.js"`

## Validation
1. `cd backend && npm run lint` (eslint clean).
2. `npm run seed:audit` against the existing DB.
3. Verify:
   - `SELECT COUNT(*) FROM audit_logs WHERE JSON_UNQUOTE(JSON_EXTRACT(details,'$.seeded_by')) = '<SEED_MARKER>';` → 10,000.
   - Every inserted `order_id` / `actor_user_id` exists
     (`SELECT COUNT(*) FROM audit_logs a LEFT JOIN orders o ON a.order_id=o.id WHERE o.id IS NULL;` → 0; same for users).
   - Sample a few rows per action and confirm `details` keys match the 3 samples.
4. Re-run once → table grows by another 10,000 (append-only confirmed).

## Open notes / risks
- If `khqrOrders` is empty (no KHQR orders yet), those slots fall back to `order_created`, so the
  effective mix shifts; acceptable for a demo.
- 10,000 rows add ~ a few MB; fine for MySQL. If performance matters, batch size is tunable.
- Append-only means manual cleanup (if ever needed) is by `seeded_by` tag, mirroring the existing
  `hasSeededOrders()` JSON_EXTRACT pattern in `seeders/orders.js:7`.
