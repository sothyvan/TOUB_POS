# Documentation Archive

This directory contains historical TouB POS planning and implementation
records. These files are retained for traceability, but they may describe old
roles, routes, feature status, or architecture.

Do not use archived documents as implementation instructions. Start with the
[active documentation index](../README.md).

## Contents

- `handoffs/` - completed phase handoff records from Phases 3 through 6.
- `plans/` - superseded implementation plans, roadmaps, and security plans.
- `reports/` - historical audits and refactoring reports.
- `reference/` - snapshots used as inputs to the current documentation suite.

Older documents that duplicated current guidance or described obsolete
authentication and KHQR behavior were removed instead of archived to avoid
misleading future contributors.
