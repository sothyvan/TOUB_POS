## 📂 Scripts Directory Structure

- `seed.js` — Main database seeding runner.
- `seeders/`
  - `data.js` — Core seed configurations.
  - `helpers.js` — Shared calculations and utility methods.
  - `users.js` — User model upserts.
  - `stalls.js` — Stall model and staff allocation registers.
  - `menu.js` — Category, product, and per-stall prices mapping.
  - `orders.js` — Fake order records, order items, audit logs, and Telegram tickets generation.
